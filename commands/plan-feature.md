# Command: plan-feature

**Invokes:** `product-analyst` → `architect`
**Use when:** starting a new feature or client request.

## Instruction
1. Run `workflows/discovery-and-requirements.md` to produce a
   requirements note and stories with acceptance criteria.
2. Run `workflows/planning.md` to size and prioritize.
3. If the feature needs a technical decision, run
   `workflows/architecture-design.md`.

## Output
A requirements note, prioritized stories, and (if needed) an
architecture note/ADR and API contract sketch — ready for
implementation.
