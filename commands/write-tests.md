# Command: write-tests

**Invokes:** `qa-engineer`
**Use when:** a feature or fix has been implemented and needs test
coverage, or acceptance criteria need to be turned into test cases.

## Instruction
Run `workflows/testing.md` against the implemented code and its
originating acceptance criteria.

## Output
A test plan and the tests themselves, or an explicit list of
untestable-as-written criteria routed back to `product-analyst`.
